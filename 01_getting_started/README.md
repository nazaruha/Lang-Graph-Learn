# Getting Started with LangGraph

This folder contains introductory experiments for learning how to build with LangGraph and LangChain Core.

## Files
- **`starter_gemini.ipynb`**: A comprehensive Jupyter notebook introducing the core concepts of LangGraph, including defining nodes, edges, states, and compiling a basic graph using Google's Gemini models.
- **`main.py`**: A simple Python script demonstrating the bare-bones setup of a LangChain application.

## Prerequisites
Make sure your root `.env` file contains a valid `GEMINI_API_KEY`.
